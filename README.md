# AI 字幕 · 本地翻译

免费为 YouTube 英语视频提供本地 AI 字幕。无需付费 API 或订阅，首次需下载约 4 GB 运行组件与模型。

支持 8 种目标语言、双语字幕（原文在上）、独立字号与颜色、位置设置、缓存和拖动进度后的优先翻译。

## 安装

当前为试用版，Edge 商店尚未上架。Windows 10/11 x64，建议 16 GB 内存和至少 12 GB 可用磁盘空间。

1. 在本仓库 Releases 下载本地服务 ZIP 并解压。
2. 双击“启动本地字幕.cmd”，在准备页下载模型并启动。
3. 在 Edge 的 `edge://extensions` 开启开发人员模式，加载包内的 `extension` 文件夹。
4. 打开或刷新 YouTube 英文视频，点击播放器底部 AI 按钮开启字幕。

以后启动本地服务即可复用模型。仅支持可读取英文字幕的视频；不提供音频识别。未缓存字幕的翻译速度和质量取决于本机性能与模型。真实视频和新电脑安装验收尚未完成。
