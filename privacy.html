处理的信息及用途

扩展仅在 YouTube 页面工作，处理当前视频的英文字幕、标题、视频 ID 与播放时间，以生成和显示译文。字幕与标题送到用户电脑上的本地翻译服务和本地模型，不发送到外部付费 AI 模型服务。本地服务只监听回环地址。

存储与同步

字幕与译文缓存保存在浏览器扩展的本地存储中。字幕语言、颜色、字号、位置和启用状态使用浏览器同步存储；开启浏览器账号同步时，这些设置可能经浏览器提供商同步到用户自己的设备。模型文件保存在 Windows 用户的 LocalAppData/YouTubeAISubtitle 文件夹。

外部连接

浏览器按正常方式连接 YouTube 获取页面及字幕。用户首次准备本地服务时，由配套应用从 GitHub 官方 Ollama 发布页面下载运行组件，并通过 Ollama 下载 Qwen3 4B 模型；这些下载服务会依其政策处理网络请求信息。扩展本身不上传音频或视频，不采集密码、付款信息，不设置广告跟踪或分析服务。

共享与控制

本产品不向发布者上传字幕或译文，不出售用户数据。用户可停止本地服务、关闭或卸载扩展。卸载扩展会删除其浏览器存储；删除本地模型目录可回收模型空间。卸载说明见配套安装包。
